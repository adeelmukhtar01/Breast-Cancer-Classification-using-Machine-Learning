# 🩺 Breast Cancer Classification using Machine Learning

A machine learning project that classifies breast cancer tumors as **Benign (B)** or **Malignant (M)** using the Breast Cancer Wisconsin Dataset. The goal of this project is to assist in the early prediction of breast cancer by comparing different machine learning algorithms and evaluating their performance.

---

## 📌 Project Overview

Breast cancer is one of the most common cancers worldwide. Early detection plays a crucial role in improving treatment outcomes and patient survival.

In this project, machine learning models are trained on medical diagnostic features to predict whether a tumor is benign or malignant. The project includes data preprocessing, exploratory analysis, model training, evaluation, and performance comparison.

---

## 📂 Dataset

**Dataset:** Breast Cancer Wisconsin Dataset

The dataset contains diagnostic measurements of breast cancer tumors and classifies them into two categories:

- **M** → Malignant
- **B** → Benign
